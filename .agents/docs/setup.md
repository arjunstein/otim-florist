# Setup & Commands — Otim Florist v3

All tooling runs **inside Docker**. Host has no PHP/Composer; only Node via
Homebrew exists on host — do not use it, keep builds reproducible.

## Container

- Service `app`, container `otim-florist-app` (`compose.yaml`)
- Start: `docker compose up -d`
- App: `http://localhost:8000` · Vite HMR: `http://localhost:5173`
- Shell: `docker compose exec app sh`

## Commands (all via `docker compose exec app …`)

| Need         | Command                                              |
| ------------ | ---------------------------------------------------- |
| Install PHP  | `docker compose exec app composer install`           |
| Install JS   | `docker compose exec app npm install --ignore-scripts` |
| Full setup   | `docker compose exec app composer setup`             |
| Dev (all-in-one) | `docker compose exec app composer dev`           |
| Tests        | `docker compose exec app composer test`              |
| Migrate      | `docker compose exec app php artisan migrate`        |
| Lint (Pint)  | `docker compose exec app ./vendor/bin/pint --test`   |
| FE build     | `docker compose exec app npm run build`              |
| FE dev       | `docker compose exec app npm run dev`                |
| FE typecheck | `docker compose exec app npm run typecheck`          |

## Fresh-Clone Checklist

1. `docker compose up -d --build`
2. `docker compose exec app composer setup`
3. Open `http://localhost:8000`

## Notes

- `.env` is gitignored; copy from `.env.example`, key generated by `composer setup`.
- SQLite file lives at `database/database.sqlite`; entrypoint fixes perms.
- Never run `php`/`composer`/`npm` on host; never commit `.env`.
